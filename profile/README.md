# Scrollport — pay-per-use API tools for AI agents

Scrollport is a pay-per-use catalog of API tools for AI agents: one connection
and one prepaid wallet give an agent verified tools for search, scraping,
enrichment, social data, media and connected apps, without provider accounts,
API keys or subscriptions.

This organisation publishes Scrollport's open Skills. Each Skill packages one
workflow that has passed an end-to-end outcome review; individual tool success
is not enough.

## Skills

- [Search and SEO](https://github.com/Scrollport/search-seo-skills): organic
  opportunity maps, content briefs and AI visibility reviews.
- [Sales and prospecting](https://github.com/Scrollport/sales-prospecting-skills):
  fast lead lists and evidence-backed account research.
- [Lead List](https://github.com/Scrollport/lead-list-skill): the lead-list
  Skill as a standalone install.
- [Media creation](https://github.com/Scrollport/media-creation-skills):
  narrated audio editions of articles and newsletters.
- [Control Skill](https://github.com/Scrollport/scrollport-control-skill): how
  an agent finds, prices and runs Scrollport tools.

## Get started

```bash
npx scrollport setup
```
